Install Aplikasi

Tambahkan MyWallet ke homescreen supaya terbuka seperti aplikasi dan tetap bisa memuat halaman utama saat koneksi tidak stabil.

MyWallet sudah berjalan sebagai aplikasi terinstall.

Jika tombol belum muncul, buka lewat Chrome/Edge Android atau menu Share di Safari lalu pilih Add to Home Screen.

Panduan Penggunaan
  1. Mulai dari Pengaturan: isi nama, dompet, saldo awal, target tabungan, jatah harian, dan sisa hari kerja.
  2. Catat transaksi: buka Catat, pilih Pengeluaran/Pemasukan/Transfer, isi nominal, tanggal, dompet, kategori, lalu simpan.
  3. Pakai Chat Catat: tekan tombol chat dan tulis contoh "makan 19000 cash" atau "bensin 50k bni".
  4. Gunakan template: centang Simpan sebagai template saat input transaksi berulang agar bisa dicatat cepat berikutnya.
  5. Kontrol budget: buka Budget untuk memberi batas per kategori, lalu pantau progresnya di Dashboard.
  6. Kelola kewajiban: tambah tagihan tetap di Pengaturan, tandai lunas dari Dashboard, lalu reset saat bulan baru.
  7. Pakai AI Insight: langsung pilih kartu analisis atau tanya bebas. Endpoint AI sudah tertanam.
  8. Backup data: ekspor JSON secara berkala sebelum pindah perangkat atau membersihkan browser.
